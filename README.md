### 🌍 [EN] Description & Features / 🇹🇷 Açıklama ve Özellikler

**English:**

INFORMATION NOT FOR THIS VERSION GO TO THE MINERCAD ULTIMATE 

MinerCad is a high-performance, tactical intelligence-gathering engine designed for cybersecurity professionals. It acts as a digital mining machine, performing deep-crawl operations to identify sensitive data points, leaked credentials, and infrastructure vulnerabilities.
* **⚡ High-Speed Extraction:** Advanced multi-threading with ThreadPoolExecutor.
* **🔍 80+ Categories:** Detects Emails, API Keys, JWT tokens, Credit Cards, and more.
* **🏗️ Tech Stack:** Identifies WordPress, React, Docker, Nginx, and other core technologies.
* **📊 Reporting:** Structured reports in JSON, TXT, HTML, or XML formats.

**Türkçe:**
MinerCad, siber güvenlik uzmanları için tasarlanmış, yüksek performanslı bir taktiksel istihbarat toplama motorudur. Hedef domainler üzerinde derin tarama yaparak hassas veri noktalarını, sızdırılmış kimlik bilgilerini ve altyapı açıklarını tespit eden bir dijital maden makinesi gibi çalışır.
* **⚡ Işık Hızında:** ThreadPoolExecutor ile eşzamanlı ve çok izlekli URL analizi.
* **🔍 80+ Kategori:** E-postalar, API anahtarları, JWT tokenları, Kredi Kartları ve çok daha fazlası.
* **🏗️ Teknoloji Analizi:** WordPress, React, Docker ve Nginx gibi teknolojileri anında tespit eder.
* **📊 Raporlama:** Verileri JSON, TXT, HTML veya XML formatlarında raporlar.
